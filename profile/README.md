# 해달 프로그래밍 (haedalprogramming) - PUBLIC

### 기술로 가치를, 교육으로 미래를 만듭니다

아이들이 코딩을 배우는 방식을 바꾸는 AI EdTech 스타트업입니다.
커리큘럼 설계부터 LMS 개발, 운영 자동화까지 — 교육의 전 과정을 직접 만듭니다.
